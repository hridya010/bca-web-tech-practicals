Q4. Image Gallery with Accessible Descriptions
Question: Create a small HTML image gallery for a college event. Each image must have meaningful alternative text and a caption where appropriate. Explain how image size and accessibility affect user experience.

Output Preview:

College Event Image Gallery

Importance of alt attribute:

  • Provides text description if image fails to load.
  • Used by screen readers for visually impaired users.
  • Improves website accessibility and SEO.

Importance of Image Size:

Large images increase webpage load time. Proper resizing and compression speed up website performance and user experience.

Internal vs External Links:

  • Internal Links: Links pointing to pages within the same website (e.g., href="faculty.html").
  • External Links: Links that take users to another website outside (e.g., href="https://www.google.com").

Purpose of Semantic Elements:

ElementPurpose
<header>Defines introductory content or navigation header.
<nav>Contains navigation links.
<main>Contains main unique content of the page.
<section>Represents a distinct section of related content.
<article>Represents independent self-contained content.
<aside>Contains related/secondary content (sidebar).
<footer>Contains footer information (copyright, credits).

Why Semantic HTML is better: It improves code readability, SEO ranking, screen reader accessibility, and maintenance.

Q7. Character Entity Challenge

Output Preview:

HTML Character Entities

Copyright: ©

Registered trademark: ®

Euro symbol: €

Plus/minus: ±

Why character entities are useful:

Some characters (like < or >) are reserved in HTML. Entities prevent browsers from mistaking text for HTML tags.

Q8. Frames Old Approach vs Modern Design

Traditional Frames vs Modern Layout:

Traditional frames (<frameset>) divided a browser window into separate HTML documents. However, they had major limitations in bookmarking, SEO, printing, and responsiveness.

Modern HTML5 with CSS Flexbox/Grid is responsive, mobile-friendly, easy to maintain, and SEO compatible.
